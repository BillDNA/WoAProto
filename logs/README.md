# logs/ — playtest data

Gameplay and content records, not codebase notes. Everything here is generated by the tools and skills; the tree ships empty (`.gitkeep`) and fills as you run them.

| Path | What lands here | Written by |
|---|---|---|
| `reports/balance/<version>/` | Balance-sweep reports + the per-version `accumulated.json` | `dev/balance-report.js`, the `generate-reports` skill |
| `reports/skirmish/<version>/` | Per-skirmish LLM transcripts + the JSONL master log (ignored) | `dev/claude-plays.js` |
| `reports/analysis/<version>/` | Graded analyses of the above | the `review-reports` skill |
| `debug/` | Debug-button state dumps (ignored) | the in-app Debug button |
| `woa.db` | Regenerable SQLite index over the reports (ignored) | `dev/db.js` |

Reports are filed by rules version (`Engine.VERSION`) so a run is only ever compared against same-version data. Committed `.md` reports are the human record; the JSONL/log/db files and `debug/` are regenerable and gitignored.

These are throwaway by design — delete freely and regenerate. Git is not their archive; a report describes one run at one moment.
